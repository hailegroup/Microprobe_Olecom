1 Overview 
This application, which is designed for Hitachi Metals digital mass flow controllers (hereafter called 
DMFC), enables the following functions via RS-485 serial communication manipulated from computer: 
Changing of setpoint (at digital control only), response waveform monitoring, valve control 
(opening/closing), comment entry on individual DMFC, changing of MFC ID and baud rate, zero 
adjustment, and alarm setting. Some DMFCs are capable of checking delivery inspection data in DMFC 
and acquiring information through the zero-point record control function.  
If a DMFC-laden process controller  exercises analog or DeviceNet control of MFC, this application 
allows saving of acquired data in files as well as simultaneous monitoring of DMFC control information, 
including setpoints, outputs and valve voltages, of multiple DMFCs, assuring no effect on process. With 
the system in digital control mode, this application enables the control of DMFC flow rate and the 
acquisition of corresponding response waveform data, which ensures easy DMFC operation check. The 
reading and control of zero-point record data stored in DMFC are available if DMFC is endowed with the 
zero-point record control function, which is of use for MFC preventive maintenance. 
 
 
 
2 Features 
Key features of this application include: 
▣ Monitoring of the items as follows as to all the connected DMFCs: DMFC ID number, serial number, 
process gas name, full-scale flow rate, conversion factor, control mode (Digital or Analog control), 
current setpoint, current output, current valve voltage, and status (presence of errors) 
▣ Setting of DMFC ID number 
▣ Setting of DMFC serial communication speed (baud rate)  
▣ DMFC control mode selection (Digital or Analog control) 
▣ Error/alarm recovery in DMFC 
▣ Comment entry on individual DMFC (up to 40 characters), comment access 
▣ Batch auto zero adjustment of individual DMFC or all the connected DMFCs 
▣ Entry of flow rate setting, monitoring of DMFC output and valve voltage, and data sending to MS 
Excel™ by this application at Digital control 
▣ For DMFC outfitted with the calibration data save function, invocation and sending (to MS Excel™) 
of calibration data containing flow setting data, N2 measured data, response time, factory-shipped 
zero-point, and pre-shipment inspection data including valve leakage 
▣ For DMFC outfitted with the zero-point record co ntrol function, reading of zero-point data [%] and 
cumulative zero-point shift amount [%] relative to the default, and reset of record data

4.4 Other Notes 
1. Acceptable Use Policy for Excel 
This application permits acquired data to be transferred to Microsoft Excel™ via DDE communication. 
Basic precautions should always be followed for safe use, including the following: 
・ Do not open more than one Excel file. Otherwise,  this application fails to recognize a desired 
file. 
・ A worksheet is to be named “Sheet*” (* is assigned with a digit such as 1, 2, 3). 
 
2. Flow control Mode 
Non-DeviceNet DMFC 
Our DMFC allows you to choose the type of flow control, analog control or digital control. Analog 
control is a default upon power supply to DMFC.  
 
[Analog control mode] 
Analog control is to control a flow rate through the adoption of 0 to 5VDC analog voltage from 
the external device. MFC setpoints issued with digital command is overridden if the system is in 
analog mode. As with digital control mode, this mode is capable of digital communication except 
for flow control. 
 
[Digital control mode] 
Digital control executes digital command via serial communication for flow control, which causes 
analog flow setting to be overridden. 
 
 
 Warning 
Digital control takes effect  only when DMFCs, except  some models, receive the 
digital control switch command through digital communication, which causes 
the flow setting from the analog connect or to be overridden and allows flow 
control with the command th rough digital communication. Note that DMFC 
operation from the system becomes disabl ed if switching of flow control from 
Analog to Digital by this application is attempted while DMFC is in process 
through analog voltage.  If temporary switching of flow control to Digital is 
performed by this application to acquire data on response waveforms, be sure 
to place DMFC in a proper control mode such as switching to Analog control. 
 
 
DeviceNet DMFC 
No analog control mode is available in this type of DMFC. DeviceNet DMFC allows flow control in 
response to DeviceNet communication command or RS485 communication command. Only setting 
command from DeviceNet is effective for flow control upon power supply to DMFC, which causes 
serial communication command to be overridden. Once DeviceNet DMFC is connected with this 
application, flow control through DeviceNet setting command and serial communication command 
become enabled. 
 
3. MFC ID Overlap 
This application enables the simultaneous connection of DMFCs, up to 63 if an individual ID number is 
assigned to each DMFC. ID numbers for all DMFCs ar e factory-configured to “7 ”. Initial use of this 
application requires single connection to DMFC. Then, network connection is to be established according 
to section 4.3 Connection with unique MFC ID numbers assigned. 
 
 
 Warning 
Abnormal operation is observed if this application detects an overlap between ID 
numbers.

5.2.3 Zero-point adjustment during polling 
 
 Caution 
The following requirements should always be satisfied before performing 
zero-point adjustment. 
 
1. DMFC flow setpoint is set at 0%. 
2. Complete shutoff of the gas is assured. 
The valve provided in DMFC is not a full shutoff valve. Ensure that the 
shutoff valve located at the DMFC upstream or downstream shuts off gas 
flow completely. 
3. Adequate warming up of DMFC is provided.  
Refer to the relevant DMFC specification for warming-up time. 
 
 
With the click of Auto zero button while DMFC is being polled, the Zero Adjust window shown below is 
displayed. The window enables you to make zero adjustment of the active MFC. 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
The method of zero adjustment falls into the following two types: 
 
1. Manual zero adjustment 
The Manual Adjust function enables manual adjustment of zero point of the active MFC to any desired 
value. This function is of use in zero-point offset adjustment if the process controller fails to read a 
negative voltage. 
・Slider : This bar is used to change a zero adjustment value. 
・Read button : This button is used to read the current zero adjustment value of the active 
DMFC. As DMFC Ver8 or earlier, the slider is reset to the center with the click of 
Read button in Fine setting.  
・Write button : This button is used to send a zero adjustment value changed with the slider to 
DMFC.

7 Trouble shooting 
 
・ No recognition of DMFC at communication start 
 
Cause 1 : Overlap between DMFC ID numbers 
Remedy 1 : Assign a unique ID number to individual DMFC to avoid overlaps. (see section 6.2) 
 
Cause 2 : Improper COM port number 
Remedy 2 : This application is capable of detecting an available communication port number upon its 
launch, which enables you to select a port from “Tool” – “COM Port setting”. Not all the 
available ports are regarded as  a RS232C communication port to capitalize on. A proper port 
number must be selected. If USB port connecting type USB485-AE1 is used, a COM port 
number is displayed in “BITS RS-485/USB Converter BSU-485/US1 (COM*)” layered under 
Port (COM and LPT) in Device Manager of Control Panel. In the example given below, a 
COM port number is set to 2. 
 
      
  
 
For changing the port number, go to Property to open Port settings tab. The following window is 
displayed with the click of Advanced button, which allows changing the COM port number. 
 
      
  
 
 
Cause 3 : Disagreement of the baud rates between MFC and software

Remedy 3 : Some of MFCs selected on the initial screen permit selection of multiple baud rates.  
MFC recognition fails if the baud rate of this software disagrees with that of MFC. 
 
Cause 4 : Inadequate Max serial ID number 
Remedy 4 : DMFC ID number is to be set to 1 to 63. The maximum ID number is required to be specified 
in “Max serial ID”, which causes an intended  MFC to fail to be detected upon communication 
start if the MFC ID number surpasses Max serial ID. Increment the number in Max serial ID. 
 
Cause 5 : No communication is established if outdated version of software is used in respect of 
 FC-D98 Series MFC. 
Remedy 5 : Contact us for details. 
 
 
・Auto zero-point adjustment failed 
 
Cause 1 : The current zero point is out of its adjustable range. 
Remedy 1 : Factory-shipped zero-point adjustment da ta is stored in DMFC. DMFC is configured to 
perform auto zero-point adjustment under the condition that comparison between the 
factory-shipped and the current zero-point adjustment data reveals a cumulative zero-point 
shift being in ±10%FS. An error is raised if the zero-point shift is out of the adjustable range, 
which disables zero-point adjustment. Potential deterioration of flow accuracy in MFC may be 
concerned. Re-calibration of flow rate is required to recover from this error.  
 
Cause 2 : Gas flow is observed. 
Remedy 2 : Auto zero-point adjustment fails and an error is raised if gas leaks into DMFC due to 
incomplete shutoff of gas flow. Ensure that gas flow is stemmed completely with the shutoff 
valve, and retry auto zero-point adjustment.
